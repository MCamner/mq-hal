mq-hal

Natural language command router for macOS — runs fully local via Ollama.

What it does

You type a natural language command. mq-hal sends it to a local Ollama model, gets back a structured JSON intent, and routes it to a safe allowlisted action — git status, git log, repo switching, or mqlaunch subcommands. The model never runs shell directly.

Demo

Input
$ mq-hal "visa git status i macos-scripts"
Model intent (JSON)
{
  "intent": "git_status",
  "repo": "macos-scripts",
  "command": null,
  "args": [],
  "message": "Visar git status."
}
Output
HAL: Visar git status.
M  scripts/hal.py

Quick start

  1. Install Ollama
    brew install ollama && brew services start ollama
  2. Pull the model
    ollama pull qwen3:4b-instruct
  3. Clone and link
    git clone https://github.com/MCamner/mq-hal.git ~/mq-hal
ln -s ~/mq-hal/bin/mq-hal ~/bin/mq-hal
  4. Configure your repos
    Edit config/repos.json with your local repo paths.
  5. Run
    mq-hal "visa senaste commits"

Safety model

The LLM only returns JSON. The Python router enforces an explicit allowlist of intents and mqlaunch subcommands. Unknown or dangerous requests get the refuse intent — no shell injection possible.
