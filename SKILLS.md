# Skills

mq-hal ships local skills for maintaining its safe router, integration stack,
runtime observability, docs, terminal UX and release readiness.

## Built-in skills

| Skill | Description |
| ----- | ----------- |
| [docs-maintainer](skills/docs-maintainer/SKILL.md) | Keep docs aligned with command behavior |
| [hal-router-safety-maintainer](skills/hal-router-safety-maintainer/SKILL.md) | Maintain intent schema, routing and safety boundaries |
| [integration-stack-maintainer](skills/integration-stack-maintainer/SKILL.md) | Maintain mqlaunch, repo-signal, mq-mcp and repo integrations |
| [release-readiness](skills/release-readiness/SKILL.md) | Prepare and verify releases |
| [repo-aware](skills/repo-aware/SKILL.md) | Work repo-first with local structure and conventions |
| [runtime-observability-maintainer](skills/runtime-observability-maintainer/SKILL.md) | Maintain runtime, vector, model and tool health summaries |
| [terminal-ui-polisher](skills/terminal-ui-polisher/SKILL.md) | Polish terminal output and operator UX |
